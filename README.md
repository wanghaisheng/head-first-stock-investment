# Head First Stock Investment

## 面向普通人的个人交易方法论

> 帮助普通投资者建立属于自己的交易体系、交易纪律与复盘机制。

《Head First Stock Investment》不是一本教人预测涨跌的书，也不是一本只罗列指标的技术分析手册。

它的定位是：

> 把普通人在真实市场中反复遇到的“什么时候买、什么时候卖、怎样守住盈利、怎样避免失控”这些问题，整理成一套可执行、可复盘、可进化的个人交易方法论。

本书从作者自己的交易经历出发：2026年5月12日开始探索使用 DeepSeek 辅助选股，到 2026年7月1日收益率达到约 105%；但由于防守体系欠缺，2026年7月17日浮盈基本归零。这个过程说明：选到好股票并不等于拥有交易体系，真正决定长期结果的是买入、持有、卖出、回撤控制与纪律执行能否形成闭环。

---

# 为什么个人交易体系重要？

普通人想通过投资实现复利，大致只有两条路。

第一条路是无脑选择指数被动 ETF 定投，用 10 年、20 年甚至更长时间，赌的是国家的未来、经济的发展、市场总盘子的变大。这条路的关键不是交易能力，而是长期信念、现金流稳定和持续持有。

第二条路是依靠自己的交易体系，在多次交易中持续累积优势，通过一次又一次可复制的买入、持有、卖出和风控，实现资金的指数级增长，完成主动型资金积累。无论是打板、趋势票，还是后续扩展出的其他方法，本质都不是某个单点技巧，而是一套能反复执行、能识别失效、能持续修正的个人交易体系。

本书选择重点讨论第二条路：

> 如果你不满足于只被动持有指数，而希望通过主动交易放大资金曲线，那么你必须先拥有自己的交易体系。

因此，本书后续所有模型都服务于同一个目的：让普通投资者不再依靠灵感和冲动交易，而是用一套清晰的体系决定什么时候买、什么时候持有、什么时候卖、什么时候认错。

同时，本书也会在第一卷建立正确的波动观：波动不是你的敌人，下跌不一定就会亏钱，暴跌之后往往存在翻倍机会；但这些机会必须通过产业逻辑、资金承接、成交额跃迁和仓位纪律来确认。

# 本书要解决的两个核心问题

## 1. 什么时候买？

本书提出的“成交额跃迁”主要用于解决建仓问题。

普通投资者最大的问题之一，是在没有资金确认、没有市场共识、没有交易计划时提前买入。成交额跃迁不是为了追逐短期放量，而是帮助交易者判断：

> 市场是否已经开始用真实资金重新定价一家公司。

因此，它是发现机会之后的买入确认工具。

## 2. 什么时候卖？

本书提出的“冲高回落程度”和“回撤程度”主要用于解决持仓与卖出问题。

很多交易者不是不会赚钱，而是不会把利润留下来。冲高回落与回撤控制的意义，不是预测最高点，而是帮助交易者判断：

> 一笔持仓是否已经从进攻状态转入风险暴露状态。

因此，它们是持仓管理、风险降级和卖出执行的纪律工具。
